
# Vulnerability Assessment & Penetration Testing Home Lab

## Project Overview

This project documents a hands-on cybersecurity assessment using Kali Linux and Metasploitable 2 in an isolated virtual lab environment.

The objective is to practice network reconnaissance, vulnerability identification, controlled exploitation, and network traffic analysis while developing professional security assessment and reporting skills.

## Lab Environment

- **Attacker Machine:** Kali Linux
- **Target Machine:** Metasploitable 2
- **Network Configuration:** Host-only network
- **Version Control:** Git and GitHub

## Tools and Technologies

- **Nmap:** Network reconnaissance and service enumeration
- **Searchsploit:** Vulnerability and exploit research
- **Metasploit Framework:** Controlled vulnerability validation
- **Wireshark:** Network traffic analysis
- **Git/GitHub:** Version control and project documentation

## Project Milestones

1. Lab Setup & Documentation
2. Network Reconnaissance
3. Vulnerability Assessment
4. Controlled Exploitation
5. Network Traffic Analysis
6. Final Security Assessment Report
7. GitHub Portfolio & Resume Documentation

## Repository Structure

- `01-reconnaissance/` - Network scanning and enumeration
- `02-vulnerability-assessment/` - Vulnerability research and findings
- `03-exploitation/` - Controlled exploitation and validation
- `04-traffic-analysis/` - Packet capture analysis
- `screenshots/` - Supporting evidence
- `reports/` - Security assessment reports
- `notes/` - Progress logs and lessons learned

## Ethical and Legal Scope

All security testing is performed against intentionally vulnerable systems within an isolated, personally controlled lab environment. No unauthorized systems are targeted.
